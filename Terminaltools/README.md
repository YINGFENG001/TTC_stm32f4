# Terminaltools

本目录整理自 `D:\XGKJproject\stm32f4\TerminaltoolsControl`，用于保存和当前 STM32 末端控制工程相关的开发资料、调试工具和协议参考。

目录按设备分类：

- `电机/`：步进电机和驱动器资料。
- `夹爪/`：FD1985/总线舵机相关协议、调试工具和 Python 测试脚本。
- `吸盘/`：EVS08 电动吸盘资料和官方控制工具。

## 电机

- `57R系列步进电机资料.pdf`：57R 系列步进电机资料。
- `MC442E步进驱动器用户使用手册.pdf`：MC442E 步进驱动器用户手册。

## 夹爪

- `舵机协议手册-入手教程.pdf`：FD1985/总线舵机入门资料。
- `舵机协议手册-内存表解析.pdf`：舵机寄存器和内存表说明，当前保护扭矩、保护时间、过载扭矩等参数配置可参考此文档。
- `舵机协议手册-磁编码版本(220403).pdf`：磁编码版本协议资料。
- `副本磁编码SMS&STS-内存表解析_220328.xlsx`：内存表电子表格版本。
- `FD1985舵机调试工具.zip`：FD 官方/配套调试工具，内含 `FD.exe`。
- `gripper_ctl2.py`：Python 版总线舵机调试脚本，包含封包、读写寄存器、同步写等参考实现。
- `test.py`：Python 调试脚本调用示例。

## 吸盘

- `JODELL钧舵EVS08系列电动吸盘通用详细说明书V1.1.pdf`：EVS08 吸盘说明书。
- `EVS08_clawControlToolV1.4.16_clean.zip`：EVS08 控制工具上位机。
