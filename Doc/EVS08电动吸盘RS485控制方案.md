# EVS08电动吸盘RS485控制方案

## 目标

通过 STM32F407 开发板板载 RS485 接口控制 EVS08 系列电动吸盘。对上位串口命令只暴露一个 `vacum` 设备，不区分两个吸盘通道；底层对 EVS08 的两个通道同步写入相同参数，并同步执行抓取/释放动作。

## 硬件接口

RS485 端口沿用野火 RS485 通信实验例程的 UART4 配置：

```text
UART  : UART4
TX    : PC10 / UART4_TX / GPIO_AF8_UART4
RX    : PC11 / UART4_RX / GPIO_AF8_UART4
RE/DE : PH9
```

方向控制逻辑：

```text
PH9 = RESET : 发送模式
PH9 = SET   : 接收模式
```

串口参数：

```text
115200, 8 data bits, no parity, 1 stop bit
```

## 对外命令

保持与夹爪命令风格一致，抓取/释放使用 `grip/release`。当前命令格式为：

```text
vacum set [min_vac:0~100(%)] [max_vac:0~100(%)] [timeout:1~255(100ms)]
vacum grip
vacum release
vacum stop
vacum status
```

示例：

```text
vacum set 30 70 10
vacum grip
vacum status
vacum release
```

参数说明：

```text
min_vac : 最小保持真空度，单位 %
max_vac : 最大真空度，单位 %
timeout : 抓取超时，单位 100ms
```

例如 `vacum set 30 70 10` 表示最小真空度 30%，最大真空度 70%，抓取超时 10 * 100ms = 1000ms。

## EVS08寄存器映射

控制寄存器从 `0x03E8` 开始，状态寄存器从 `0x07D0` 开始。

```text
0x03E8 low byte : 控制位
  bit0 rACT      使能
  bit1 rMODE_CH1 通道1高级模式
  bit2 rATR_CH1  通道1破真空/释放
  bit3 rGTO_CH1  通道1吸取/调节
  bit4 rMODE_CH2 通道2高级模式
  bit5 rATR_CH2  通道2破真空/释放
  bit6 rGTO_CH2  通道2吸取/调节

0x03E9 high byte : 通道1最大真空度/压力
0x03EA low byte  : 通道1抓取超时时间，单位 100ms
0x03EA high byte : 通道1最小真空度/压力

0x03EB low byte  : 通道2最大真空度/压力
0x03EB high byte : 通道2抓取超时时间，单位 100ms
0x03EC low byte  : 通道2最小真空度/压力

0x03ED low byte  : 控制模式，0x00=Modbus RTU，0x55=IO控制
```

真空度换算：

```text
EVS08寄存器值 = 100 - 用户输入真空度百分比

例如 max_vac=70%，写入值为 30。
例如 min_vac=30%，写入值为 70。
例如 timeout=10，表示 1000ms，写入值为 10。
```

## 动作控制字

底层对两个通道同步操作。

```text
idle/stop:
  rACT=1, rMODE_CH1=1, rMODE_CH2=1
  control = 0x0013

grip:
  rACT=1, rMODE_CH1=1, rGTO_CH1=1, rMODE_CH2=1, rGTO_CH2=1
  control = 0x005B

release:
  rACT=1, rMODE_CH1=1, rATR_CH1=1, rMODE_CH2=1, rATR_CH2=1
  control = 0x0037
```

当前实现中，`release` 只写入一次 `release` 控制字，不再立即补写 `stop/idle`。现场测试中立即补 idle 可能过早取消破真空动作；如需强制停止，可单独发送 `vacum stop`。

## 状态读取

`vacum status` 通过 Modbus 功能码 `0x04` 读取输入寄存器 `0x07D0` 起始的 8 个寄存器，并打印：

```text
state1/state2 : 两个通道状态寄存器原始值
fault         : 故障寄存器
busy1/busy2   : 通道忙状态
obj1/obj2     : 物体检测状态位
vac1/vac2     : 当前真空度百分比
temp          : 设备温度
bus           : 总线电压
```

实测抓取到物体时，`vac1/vac2` 会从 0% 上升；未吸到物体时保持 0% 属于正常现象。

## 默认参数

```text
slave_id = 9
min_vac  = 30%
max_vac  = 70%
timeout  = 10(100ms)，即 1000ms
```

如果现场设备地址不是 `9`，优先修改 `User/vacum/bsp_evs08.h` 中的 `EVS08_DEFAULT_SLAVE_ID`。
