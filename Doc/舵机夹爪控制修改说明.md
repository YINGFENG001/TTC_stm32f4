# 舵机夹爪控制修改说明

本说明仅记录当前工程中已经保留的夹爪控制改动，按代码文件对应整理。

## 修改文件

### `Project/Fire-F407.uvprojx`

- 新增 `User/gripper/` 下 3 个源码文件到 Keil 工程。
- 命令分发文件切换为 `User/stepper/bsp_device_usart_ctl.c`。
- 增加 `--no-multibyte-chars` 编译选项。

### `User/main.c`

- 引入 `bsp_device_usart_ctl.h`。
- 上电增加 `BusServo_Init()`，初始化夹爪 `UART5`。

### `User/usart/bsp_debug_usart.c`

- 在 `HAL_UART_MspInit()` 中增加 `UART5` GPIO 初始化。
- 夹爪串口引脚：
  - `PC12`：`UART5_TX`
  - `PD2`：`UART5_RX`

### `User/gripper/bsp_gripper_uart.h`

- 定义夹爪专用串口硬件资源。
- 固定夹爪通信口为 `UART5`。

### `User/gripper/bsp_gripper_uart.c`

- 实现夹爪串口配置、发送、接收、清空接收缓存。
- 使用 HAL 阻塞收发，适配问答式舵机协议。

### `User/gripper/bsp_bus_servo.h`

- 定义舵机协议常量、寄存器地址、默认 `ID=10`。
- 定义 `BusServoStatus` 状态结构体。

### `User/gripper/bsp_bus_servo.c`

- 实现舵机协议封包、收包、校验和寄存器读写。
- `BusServo_ReadStatus()` 固定读取 `0x38` 开始的基础 8 字节状态。
- 增加 `0x41` 舵机状态、`0x45` 当前电流读取接口。
- 对 `0x3C` 当前负载做幅值/方向解码，避免误判。

### `User/gripper/bsp_gripper.h`

- 定义夹爪业务参数范围。
- 当前标定位置：
  - `open = 700`
  - `close = 2048`

### `User/gripper/bsp_gripper.c`

- 实现 `open / close / move / grip / release` 业务动作。
- `open / close / move` 使用反馈式运动，到位、堵转、超时均可返回结果。
- `grip` 使用 `0x3C` 当前负载做分步夹取。
- `release` 使用“卸力 -> 读位置 -> 上扭矩 -> 小幅退开”流程。

### `User/stepper/bsp_device_usart_ctl.h`

- 作为当前统一的设备串口命令分发头文件。

### `User/stepper/bsp_device_usart_ctl.c`

- 将原串口命令分发扩展为多设备接口：`mtor1`、`mtor2`、`clamp`、`vacum`。
- 增加夹爪命令：
  - `clamp ping`
  - `clamp status`
  - `clamp readreg [addr]`
  - `clamp open`
  - `clamp close`
  - `clamp move [openPos/Pct]`
  - `clamp grip [load] [openPos/Pct]`
  - `clamp release`
  - `clamp set [speed] [gripStep] [releaseDelta]`
- `status` 总览中增加夹爪完整状态输出。
- `?` 和启动提示中补充夹爪命令、范围和单位。

## 硬件接线

### 调试串口

- `USART1`
- `PB7`：`TX`
- `PB6`：`RX`

### 夹爪串口

- `UART5`
- `PC12`：STM32 `TX`
- `PD2`：STM32 `RX`
- `GND`：与夹爪驱动板共地

当前实测可用接线为：

- `PC12/UART5_TX -> 驱动板 TXD`
- `PD2/UART5_RX -> 驱动板 RXD`
- `GND <-> GND`

## 当前可用夹爪命令

```text
clamp ping [id]
clamp status [id]
clamp readreg [addr]
clamp open
clamp close
clamp move [openPos/Pct]
clamp grip [load] [openPos/Pct]
clamp release
clamp set [speed] [gripStep] [releaseDelta]
```

- `openPos/Pct` 支持绝对位置 `700~2048` 或开度百分比 `0%~100%`；`700` = `100%` 张开，`2048` = `0%` 闭合。
- `clamp move 100%` 与 `clamp move 700` 等同。
- `status` 和动作返回中的位置统一显示为 `openPos/Pct = 700 (100.0%)`。
- `grip [load] [openPos/Pct]` 中 `openPos/Pct` 为可选参数。
