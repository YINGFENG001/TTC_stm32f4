# 双电机停止命令与方向修正方案

本说明仅记录当前工程中已经保留的双电机停止命令和方向修正改动，按代码文件对应整理。

## 修改文件

### `User/stepper/bsp_stepper_init.h`

- 在 `StepperHw` 结构体中增加 `dir_inverted` 字段。
- 用于按电机分别配置方向输出是否反相。

### `User/stepper/bsp_stepper_init.c`

- 在 `stepper_hw[]` 中补充每台电机的方向反相配置。
- 当前实测配置为：
  - `mtor1 dir_inverted = 1`
  - `mtor2 dir_inverted = 0`
- 当前语义为：正数命令时两台电机均为顺时针。

### `User/stepper/bsp_stepper_T_speed.h`

- 增加 `Stepper_Stop(uint8_t motor_id)` 声明。

### `User/stepper/bsp_stepper_T_speed.c`

- 增加 `Stepper_GetDirLevel()`，根据 `dir_inverted` 计算实际方向电平。
- 在 `stepper_move_T()` 中，方向输出改为按单电机配置反相。
- 增加 `Stepper_Stop()`：
  - 关闭对应通道输出
  - 关闭对应比较中断
  - 清除运行标志
  - 必要时关闭 TIM8
- 停止策略为立即停机，不继续追原目标。

### `User/stepper/bsp_device_usart_ctl.c`

- 在帮助命令 `?` 和启动提示中增加 `stop` 说明。
- 在 `Stepper_Command()` 中增加：
  - `mtor1 stop`
  - `mtor2 stop`
- 停止后输出当前停下位置。

## 当前可用命令

```text
mtor1/2 move [rev]
mtor1/2 stop
mtor1/2 rpm [value]
mtor1/2 set [accel] [decel] [gear] [micro]
mtor1/2 status
```

## 当前方向约定

- `move 10`：顺时针定长运动
- `move -10`：逆时针定长运动
- `move +0`：顺时针持续旋转，直到 `stop`
- `move -0`：逆时针持续旋转，直到 `stop`
- `move` 和连续运行中的 `rpm` 回显会打印 `dir=CW/CCW`；正数为 `CW`，负数为 `CCW`

当前电机方向适配：

- `mtor1`：反相
- `mtor2`：不反相

## 说明

- 这次停止命令为立即停机，不做软减速停机。
- 停止后保留当前位置计数，可继续通过 `status` 查询。
