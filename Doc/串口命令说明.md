# 串口命令说明

本文集中说明当前 STM32 串口命令，便于 ROS 端和人工调试端参考开发。当前调试串口为 `USART1 115200 8N1`，每条命令以换行结束。

## 总体规则

同一串口同时支持两类命令：

- ROS 命令：以 `#<id>` 开头，例如 `#12 mtor1 move 50`。
- 人工命令：不带 `#<id>`，例如 `mtor1 move 50`。

接收入口是同一个 `DealSerialData()`：

```text
DealSerialData()
  -> RosProtocol_TryDispatch()
       # 开头则按 ROS 协议处理
       非 # 开头返回 FALSE
  -> Command_Dispatch()
       人工命令处理
```

核心设备动作基本共用底层控制代码。ROS 层额外负责：

- `#<id>` 请求编号解析。
- 输出 `@ack`、`@done`、`@state`、`@err`。
- 步进电机异步 `move` 的完成回报绑定。

人工命令主要用于现场调试，输出是人可读文本；ROS 命令主要用于程序解析，输出以 `@` 开头。

## 命令一致性

当前设备命令如下：

| 设备 | 统一命令 |
| --- | --- |
| `mtor1/mtor2` | `status`、`move`、`stop`、`rpm`、`set` |
| `clamp` | `ping`、`status`、`readreg`、`open`、`close`、`move`、`grip`、`release`、`set` |
| `vacum` | `status`、`set`、`grip`、`release`、`stop` |

ROS 和人工命令的差异只在协议包装和输出格式上：

- ROS 命令前面必须加 `#<id>`，输出统一为 `@ack/@done/@state/@err` 等格式。
- 人工命令不加 `#<id>`，输出为人可读文本。
- 人工侧 `?` 只用于现场帮助打印，ROS 侧不提供对应命令，避免混入非 `@` 行影响 ROS 解析。

## ROS 输出格式

常见输出：

```text
@ack id=<id> dev=<dev> cmd=<cmd> result=ok ...
@done id=<id> dev=<dev> cmd=<cmd> result=ok ...
@state id=<id> dev=<dev> result=ok ...
@err id=<id> dev=<dev> cmd=<cmd> code=<code> [detail=...]
@warn dev=<dev> event=... ...
@fault dev=<dev> event=... ...
```

`code` 常见值：

```text
ok
busy
disabled
param_error
range_error
uart_error
timeout
crc_error
id_error
device_error
unknown_device
unknown_action
```

说明：

- ROS `move` 对步进电机是异步动作，启动成功后先返回 `@ack`，运动完成后再返回 `@done`。
- 夹爪和吸盘动作当前为同步调用，动作完成或底层调用返回后直接输出 `@done` 或 `@ack`。
- 后台监控异常使用 `@warn`、`@fault`，不携带 ROS 请求 `id`。

## ROS 命令

### 系统状态

```text
#<id> status
```

示例：

```text
#1 status
```

可能输出：

```text
@state id=1 dev=mtor1 result=ok enabled=1 running=0 rev=0 target=0 err=0 accel=400 decel=400 rpm=200 gear=1:1 micro=4
@state id=1 dev=mtor2 result=ok enabled=1 running=0 rev=0 target=0 err=0 accel=30 decel=30 rpm=30 gear=20:1 micro=4
@state id=1 dev=clamp result=ok servo_id=10 openPos/Pct = 700 (100.0%) speed=0 load=0 voltage=120 temp=30 current=0 state=0x00
@state id=1 dev=vacum result=ok state1=0x0000 state2=0x0000 fault=0x0000 busy1=0 busy2=0 obj1=0 obj2=0 vac1=0 vac2=0 temp=30 bus=240
@done id=1 dev=system cmd=status result=ok
```

### ROS 步进电机

设备名：

```text
mtor1
mtor2
```

命令：

```text
#<id> mtor1 status
#<id> mtor1 move [rev]
#<id> mtor1 stop
#<id> mtor1 rpm [value]
#<id> mtor1 set [accel] [decel] [gear] [micro]
```

`mtor2` 同理。

参数：

- `rev`：单位 `0.1圈`，例如 `50` 表示 `5.0圈`。
- `move +0`：连续顺时针运行。
- `move -0`：连续逆时针运行。
- `rpm N`：连续运行目标速度为 `N rpm`，方向为顺时针。
- `rpm -N`：连续运行目标速度为 `N rpm`，方向为逆时针。
- `rpm 0`：连续运行按当前减速度降速停止。
- `set`：同时设置 `accel`、`decel`、`gear`、`micro`。
- `accel/decel`：单位 `rpm/s`，按当前设备输出轴等效值检查范围。
- `gear`：格式如 `20:1`。
- `micro`：细分数。

示例：

```text
#10 mtor1 move 50
```

输出：

```text
@ack id=10 dev=mtor1 cmd=move result=ok rev=50 dir=CW
@done id=10 dev=mtor1 cmd=move result=ok rev=50
```

连续运行：

```text
#11 mtor2 move +0
#12 mtor2 rpm 50
#13 mtor2 rpm -20
#14 mtor2 rpm 0
#15 mtor2 stop
#16 mtor2 set 30 30 20:1 4
```

可能输出：

```text
@ack id=11 dev=mtor2 cmd=move result=ok rev=0 continuous=1 dir=CW
@ack id=12 dev=mtor2 cmd=rpm result=ok value=50 dir=CW
@ack id=13 dev=mtor2 cmd=rpm result=ok value=-20 dir=CCW
@ack id=14 dev=mtor2 cmd=rpm result=ok value=0 dir=STOP
@ack id=15 dev=mtor2 cmd=stop result=ok rev=817
@ack id=16 dev=mtor2 cmd=set result=ok accel=30 decel=30 gear=20:1 micro=4
```

注意：

- 运行中动态调速只面向连续运行；定长 `move [rev]` 运行中设置 `rpm` 会返回 `busy`。
- `set` 运行中会返回 `busy`。

### ROS 夹爪

设备名：

```text
clamp
```

命令：

```text
#<id> clamp status [servo_id]
#<id> clamp ping [servo_id]
#<id> clamp readreg [addr]
#<id> clamp move [openPos/Pct]
#<id> clamp open
#<id> clamp close
#<id> clamp grip [load] [openPos/Pct]
#<id> clamp release
#<id> clamp set [speed] [gripStep] [releaseDelta]
```

参数：

- 默认舵机 ID：`10`。
- `openPos/Pct` 支持两种输入：
  - 绝对位置：`700~2048`。
  - 带 `%` 的实测物理开度：`0%~100%`。
- `700` 等同 `100%`，表示最大张开，实测约 `72mm`。
- `2048` 等同 `0%`，表示闭合。
- `load`：单位 `0.1%`，范围 `100~750`。
- 默认 `speed=1000`、`gripStep=30`、`releaseDelta=100`。

示例：

```text
#20 clamp status
#20 clamp ping 10
#20 clamp readreg 35
#21 clamp move 100%
#22 clamp move 700
#23 clamp grip 300
#24 clamp grip 300 60%
#25 clamp release
#26 clamp set 1000 30 100
```

可能输出：

```text
@state id=20 dev=clamp result=ok servo_id=10 openPos/Pct = 700 (100.0%) speed=0 load=0 voltage=120 temp=30 current=0 state=0x00
@ack id=20 dev=clamp cmd=ping result=ok servo_id=10
@state id=20 dev=clamp result=ok servo_id=10 addr=35 value=200
@done id=21 dev=clamp cmd=move result=ok openPos/Pct = 700 (100.0%) load=0 current=0 state=0x00
@done id=23 dev=clamp cmd=grip result=ok load=300 current=180 state=0x00
@done id=25 dev=clamp cmd=release result=ok openPos/Pct = 900 (79.2%) current=0 state=0x00
@ack id=26 dev=clamp cmd=set result=ok speed=1000 gripStep=30 releaseDelta=100
```

注意：

- `open`、`close`、`move` 到位后会自动取消扭矩使能。
- `grip` 成功后会进入后台 PI 保力。
- `clamp readreg 34/35/36` 可用于检查舵机保护参数，当前初始化目标为 `34=20`、`35=200`、`36=80`。

### ROS 吸盘

设备名：

```text
vacum
```

命令：

```text
#<id> vacum status
#<id> vacum set [min_vac] [max_vac] [timeout]
#<id> vacum grip
#<id> vacum release
#<id> vacum stop
```

参数：

- `min_vac`：最小真空度，`0~100%`。
- `max_vac`：最大真空度，`0~100%`。
- `timeout`：单位 `100ms`，范围 `1~255`。

示例：

```text
#30 vacum set 30 70 10
#31 vacum grip
#32 vacum status
#33 vacum release
#34 vacum stop
```

可能输出：

```text
@ack id=30 dev=vacum cmd=set result=ok min=30 max=70 timeout=10
@ack id=31 dev=vacum cmd=grip result=ok
@state id=32 dev=vacum result=ok state1=0x0001 state2=0x0001 fault=0x0000 busy1=0 busy2=0 obj1=1 obj2=1 vac1=60 vac2=62 temp=30 bus=240
@ack id=33 dev=vacum cmd=release result=ok
@ack id=34 dev=vacum cmd=stop result=ok
```

后台吸盘掉落：

```text
@fault dev=vacum event=drop vac1=0 vac2=0 obj1=0 obj2=0 action=stop
```

## 人工命令

人工命令不带 `#<id>`，主要用于串口助手现场调试。

### 通用人工命令

```text
?
status
```

示例：

```text
?
status
```

说明：

- `?` 打印详细帮助。
- `status` 依次打印 `mtor1`、`mtor2`、`clamp`、`vacum` 状态。

### 人工步进电机命令

```text
mtor1/2 move [rev]
mtor1/2 stop
mtor1/2 rpm [value]
mtor1/2 set [accel] [decel] [gear] [micro]
mtor1/2 status
```

参数：

- `rev`：单位 `0.1圈`。
- `move +0`：连续顺时针运行。
- `move -0`：连续逆时针运行。
- `rpm N`：设置连续运行目标速度和方向。
- `rpm -N`：反向动态调速。
- `rpm 0`：减速停止。
- `set` 可设置 `accel`、`decel`、`gear`、`micro`，其中 `gear` 格式如 `20:1`。

示例：

```text
mtor1 status
mtor1 move 50
mtor1 move -50
mtor1 move +0
mtor1 rpm 100
mtor1 rpm -50
mtor1 rpm 0
mtor1 stop
mtor2 set 30 30 20:1 4
```

### 人工夹爪命令

```text
clamp ping [id]
clamp status [id]
clamp readreg [addr]
clamp open
clamp close
clamp move [openPos/Pct]
clamp grip [load] [openPos/Pct]
clamp release
clamp set [speed] [gripStep] [releaseDelta]
```

示例：

```text
clamp ping 10
clamp status
clamp readreg 35
clamp move 100%
clamp move 700
clamp grip 300
clamp grip 300 60%
clamp release
clamp set 1000 30 100
```

说明：

- `clamp readreg 34/35/36` 可用于检查舵机保护参数。
- 当前初始化目标为 `34=20`、`35=200`、`36=80`。
- `clamp grip [load]` 当前上限为 `750`。

### 人工吸盘命令

```text
vacum set [min_vac] [max_vac] [timeout]
vacum grip
vacum release
vacum stop
vacum status
```

示例：

```text
vacum set 30 70 10
vacum grip
vacum status
vacum release
vacum stop
```

## 自动上报

除命令响应外，后台状态机还可能主动输出：

```text
@info dev=clamp event=hold_pi ...
@info dev=clamp event=hold_stable ...
@warn dev=clamp event=status_error ... action=retry
@fault dev=clamp event=status_error ... action=torque_off
@fault dev=clamp event=drop ... action=torque_off

@warn dev=vacum event=status_error ... action=retry
@fault dev=vacum event=status_error ... action=stop
@fault dev=vacum event=drop ... action=stop

@fault dev=system event=last_fault ...
@fault dev=system event=last_reset reset=iwdg
```

ROS 端建议：

- 以 `@ack/@done/@state/@err/@warn/@fault` 作为行首分类。
- 对带 `id=` 的响应按请求编号匹配。
- 对不带 `id=` 的 `@warn/@fault` 按设备和事件处理为异步告警。
- 步进 `move` 要等待对应 `@done` 才认为定长动作完成。
