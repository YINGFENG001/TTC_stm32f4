# 双电机步进控制修改说明

本说明仅基于当前工作区 `git diff` 整理，用于对应本次代码改动。

## 修改文件总览

当前与原始工程相比，主要改动文件如下：

- `User/key/bsp_exti.c`
- `User/main.c`
- `User/stm32f4xx_it.c`
- `User/stepper/bsp_stepper_init.h`
- `User/stepper/bsp_stepper_init.c`
- `User/stepper/bsp_stepper_T_speed.h`
- `User/stepper/bsp_stepper_T_speed.c`
- `User/stepper/bsp_stepper_usart_ctl.h`
- `User/stepper/bsp_stepper_usart_ctl.c`
- `.gitignore`

## 各文件修改点

### 1. `User/stepper/bsp_stepper_init.h`

- 将原来的单电机宏切换方式改为双电机硬件配置表 `stepper_hw[]`。
- 增加 `STEPPER_NUM`、`STEPPER_MOTOR_0`、`STEPPER_MOTOR_1`。
- 增加 `StepperHw` 结构体，用于统一描述每台电机的 DIR/ENA/PUL 端口、定时器通道和中断标志。
- 将 `MOTOR_EN`、`MOTOR_DIR`、`MOTOR_PUL` 宏改为带 `motor_id` 的写法。

### 2. `User/stepper/bsp_stepper_init.c`

- 新增 `stepper_hw[2]`，固定映射两台电机的硬件资源：
  - `mtor1`：`PE0 / PE1 / PI5 / TIM8_CH1`
  - `mtor2`：`PE4 / PI8 / PI6 / TIM8_CH2`
- GPIO 初始化改为同时初始化两台电机的 ENA、DIR、PUL 引脚。
- TIM8 输出比较初始化改为同时配置 CH1 和 CH2。
- `TIM8_CC_IRQHandler` 中分别调用 `speed_decision(0)` 和 `speed_decision(1)`。

### 3. `User/stepper/bsp_stepper_T_speed.h`

- 将单电机运行状态改为双电机数组接口。
- 增加 `StepperCmdResult` 返回值枚举。
- 新增 `Stepper_SetMotorPulsesPerRev()` 声明，用于按电机实际每圈脉冲数设置底层参数。
- 将 `TIM_PRESCALER` 调整为 `31`。
- 增加 `motor_status[]`、`Stepper_IsAnyRunning()` 等双电机运行状态接口。

### 4. `User/stepper/bsp_stepper_T_speed.c`

- 将原来的单电机变量改为双电机数组：`srd[]`、`stepPosition[]`、`motor_status[]`。
- 新增 `stepper_pulses_per_rev[]`，支持每台电机单独设置每圈脉冲数。
- `stepper_move_T()` 改为 `stepper_move_T(motor_id, ...)`，并增加：
  - ID 检查
  - 使能检查
  - 运行中 busy 检查
  - 参数有效性检查
- 梯形加减速系数改为按当前电机的每圈脉冲数实时计算，不再固定假设 32 细分。
- `speed_decision()` 改为按 `motor_id` 分别处理 CH1/CH2 中断和速度状态机。
- 增加全局运行状态同步函数 `Stepper_UpdateGlobalStatus()`。

### 5. `User/stepper/bsp_stepper_usart_ctl.h`

- 增加 `Device_Task()` 和 `Device_ReportDone()` 声明。
- 增加 `string.h` 依赖，供命令解析使用。

### 6. `User/stepper/bsp_stepper_usart_ctl.c`

- 将原来的旧串口命令体系重构为名称式双电机命令：`mtor1`、`mtor2`。
- 增加设备配置结构：
  - `StepperMechanicalConfig`
  - `StepperSafetyLimit`
  - `StepperParam`
  - `StepperDeviceConfig`
  - `EndDevice`
- 两台电机当前机械参数：
  - `mtor1`：`200步/圈`、`8细分`、`1:1直驱`
  - `mtor2`：`200步/圈`、`8细分`、`20:1减速机`，输出轴 `rpm` 范围 `1~30`，默认 `30`
- 输入单位统一为：
  - `rev`：`0.1圈`
  - `accel`：`rpm/s`
  - `decel`：`rpm/s`
  - `rpm`：`rpm`
- 默认参数：
  - `rev = 50`（5圈）
  - `accel = 100`
  - `decel = 100`
  - `mtor1 rpm = 100`
  - `mtor2 rpm = 30`
- 参数范围：
  - `rev = -100000 ~ 100000`
  - `accel = 60 ~ 500`
  - `decel = 60 ~ 500`
  - `mtor1 rpm = 1 ~ 600`
  - `mtor2 rpm = 1 ~ 30`
- 增加两级范围检查：
  - 用户输入范围检查
  - 电机轴等效范围检查
- 启动提示改为只打印设备、单位、默认值和范围。
- 输入 `?` 时打印命令说明和示例。
- 输入 `status` 时打印两台电机状态，并追加空行。
- 启动时不再自动打印状态；`clamp`、`vacum` 也不再出现在 `status` 输出中。

### 7. `User/main.c`

- 主循环从单纯 `DealSerialData()` 改为非阻塞轮询：
  - `DealSerialData()`
  - `Device_Task()`
  - `Device_ReportDone()`

### 8. `User/stm32f4xx_it.c`

- 串口接收中断去掉“电机运行时拒收命令”的限制。
- 现在电机运行过程中仍可继续接收新的串口命令。

### 9. `User/key/bsp_exti.c`

- 增加 `bsp_stepper_T_speed.h` 头文件引用。
- 使按键控制和当前双电机速度控制接口保持一致。

### 10. `.gitignore`

- 新增 Keil/MDK 中间构建文件忽略规则。
- 主要忽略：
  - `Output/`
  - `Listings/`
  - `Project/*.uvoptx`
  - `Project/*.uvguix.*`
  - 常见中间构建扩展名
- `Doc/` 目录不忽略，文档会继续纳入版本管理。

## 当前代码对应的功能结果

1. 支持两台步进电机独立控制：`mtor1`、`mtor2`。
2. `mtor1` 为 `200步/圈、8细分、1:1直驱`，`mtor2` 为 `200步/圈、8细分、20:1减速机`，mtor2 输出轴 `rpm` 范围为 `1~30`。
3. 底层使用 TIM8 双通道输出比较模式：
   - `mtor1` -> `TIM8_CH1`
   - `mtor2` -> `TIM8_CH2`
4. 串口命令为名称式、非阻塞控制。
5. 启动时只显示参数概览；输入 `?` 显示命令说明；输入 `status` 显示电机状态。
