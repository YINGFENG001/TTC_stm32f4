# 双电机步进控制修改说明

本文只保留当前代码版本对应的说明，用于对照双路步进电机控制、统一设备命令分发和参数范围。

## 当前文件分工

- `User/stepper/bsp_stepper_init.h`
  - 定义双路步进硬件资源数量、编号、TIM8 通道和引脚宏。
  - 定义 `StepperHw`，统一描述每台电机的 `DIR/ENA/PUL` 引脚、比较通道、中断标志和方向反相配置。
- `User/stepper/bsp_stepper_init.c`
  - 固定映射两台电机硬件：
    - `mtor1`：`ENA PE0`，`DIR PE1`，`PUL PI5 / TIM8_CH1`
    - `mtor2`：`ENA PE4`，`DIR PI8`，`PUL PI6 / TIM8_CH2`
  - 初始化 GPIO、TIM8 输出比较 Toggle 模式和 TIM8 CC 中断。
  - `MOTOR_PUL_IRQHandler()` 分别调用 `speed_decision(STEPPER_MOTOR_0)` 和 `speed_decision(STEPPER_MOTOR_1)`。
- `User/stepper/bsp_stepper_T_speed.h/.c`
  - 实现双路步进底层梯形加减速和脉冲输出。
  - 保存 `srd[]`、`stepPosition[]`、`motor_status[]` 等每台电机独立运行状态。
  - 提供 `stepper_move_T()`、`Stepper_RunContinuous()`、`Stepper_Stop()` 和 `Stepper_SetMotorPulsesPerRev()`。
- `User/stepper/bsp_stepper_ctl.h/.c`
  - 实现 `mtor1/mtor2` 命令处理和 ROS 共用的 `DeviceApi_Stepper*()`。
  - 负责输出轴单位与电机轴单位换算、用户参数范围检查、电机轴等效范围检查。
  - 对外暴露 `Stepper_Command()`，由统一设备分发层调用。
- `User/stepper/bsp_device_usart_ctl.h/.c`
  - 保留统一串口命令入口、设备表 `devices[]`、`Device_Task()`、`Device_ReportDone()`、`ShowHelp()` 和全局 `status` 命令。
  - 根据设备名分发到 `Stepper_Command()`、`Clamp_Command()`、`Vacum_Command()`。
  - `Device_Task()` 刷新步进电机状态，并调度 `Clamp_HoldTask(now)`、`Vacum_MonitorTask(now)`。
- `User/stepper/bsp_device_context.h`
  - 定义跨设备共享的 `EndDevice`、设备编号、设备状态和快速检测周期等公共上下文。

## 当前机械和参数配置

- `mtor1`
  - 机械参数：`200步/圈`，`4细分`，`1:1直驱`
  - 默认输出轴 rpm 范围：`1~1500`
  - 默认 rpm：`200`
  - 默认 accel/decel：`400 rpm/s`
- `mtor2`
  - 机械参数：`200步/圈`，`4细分`，`20:1减速机`
  - 默认输出轴 rpm 范围：`1~75`
  - 默认 rpm：`30`
  - 默认 accel/decel：`30 rpm/s`
- 通用参数
  - `rev`：`-10000.0~10000.0` 圈，命令输入单位为 `0.1圈`
  - `accel`：`rpm/s`，有效范围由当前 `gear` 和电机轴 `40~1000 rpm/s` 动态决定
  - `decel`：`rpm/s`，有效范围由当前 `gear` 和电机轴 `40~1000 rpm/s` 动态决定
  - 电机轴等效最高转速：`1500 rpm`，输出轴 rpm 上限会随当前 `gear` 动态计算

## 当前命令

```text
mtor1/2 move [rev]
mtor1/2 stop
mtor1/2 rpm [value]
mtor1/2 set [accel] [decel] [gear] [micro]
mtor1/2 status
```

- `move [rev]` 使用当前保存的 `accel/decel/rpm` 参数启动运动。
- `rpm [value]` 设置输出轴转速，并打印当前设置、范围和目标方向；在 `move +0/-0` 连续运行期间会动态调速。
- `set [accel] [decel] [gear] [micro]` 设置加速度、减速度、减速比和细分；`gear` 格式如 `20:1`。
- `move +0` 表示正向连续旋转，`move -0` 表示反向连续旋转，直到手动 `stop`；连续运行中调速斜坡使用当前 `set` 保存的 `accel/decel`。
- `move` 和连续运行中的 `rpm` 回显会打印 `dir=CW/CCW`；正数为 `CW`，负数为 `CCW`。
- 连续运行期间 `rpm 0` 表示按 `decel` 减速到停止，`rpm N` 表示目标方向为 `CW`，`rpm -N` 表示按 `decel` 减速后反向到 `CCW` 并按 `accel` 升到 `N rpm`。
- 保存的 `rpm` 永远为正数；定长 `move [rev]` 的方向只由 `rev` 正负决定。
- 定长 `move [rev]` 运行期间暂不支持动态调速，此时执行 `rpm [value]` 返回 `busy`。
- `status` 会打印当前位置、目标位置、当前参数和限制范围。
- 全局 `status` 会依次打印 `mtor1`、`mtor2`、`clamp`、`vacum` 状态。

## 底层脉冲和加减速

- TIM8 使用输出比较 Toggle 模式产生脉冲。
- `TIM_PRESCALER = 31`，定时器计数频率约为 `5.25MHz`。
- `TIM_PERIOD = 0xFFFF`，比较值按当前计数值加半周期延时装载。
- 每经过两个 Toggle 边沿，代码认为输出了一个完整步进脉冲，并推进一次梯形加减速状态机。
- 每台电机的每圈脉冲数按 `电机步数 * 细分` 设置，目前默认 `200 * 4 = 800` 脉冲/电机轴圈。
- `rpm` 为输出轴转速，会按减速比换算到电机轴转速，再换算为底层角速度参数。
- `accel/decel` 为命令侧加减速度，内部按当前减速比换算为电机轴加减速度，并受电机轴 `40~1000 rpm/s` 限制。

## 底层维护要点

- `speed_decision()` 在 TIM8 比较中断中运行，后续维护时应避免在该路径中加入 `printf`、`sqrt`、浮点换算或复杂全局扫描。
- 动态调速运行参数由 `Stepper_UpdateContinuousSpeedSigned()` 更新，涉及多字段同步时必须继续使用关中断临界区保护。
- ISR 内部计数状态已经放在文件级 static 变量中，并由 `Stepper_ResetIsrState()` 在启动、停止和 STOP 状态边界复位；后续新增停止路径时也要同步复位这些状态。
- 比较值装载使用上一轮 CCR 累加半周期延时，降低 ISR 进入时间抖动对脉冲周期的影响；如调整该逻辑，需要同时验证高速脉冲稳定性。
- `set [accel] [decel] [gear] [micro]` 会改变机械换算和每圈脉冲数，运行中保持禁止，避免运行期间改变底层脉冲尺度。
